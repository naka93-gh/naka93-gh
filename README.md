# こんにちは 👋

ソフトウェアエンジニアです。リポジトリには使いたいものを自分で作って置いています。

## About

- TypeScript をメインに、必要に応じて Rust も書きます。
- 開発者向けツールや業務効率化ツールなど、「自分が欲しいもの」を中心に開発しています。
